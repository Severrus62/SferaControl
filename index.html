Подключение и начало работы

API уже указан: https://sheetdb.io/api/v1/c6f4utofinhio. На листе, выбранном в SheetDB по умолчанию, первая строка должна содержать заголовки id в A1 и project в B1. Каждая следующая строка — один проект; поле project содержит JSON всей карточки, включая этапы и счета. Не меняйте эти значения вручную.

В SheetDB разрешите чтение, создание, изменение и удаление строк. Если ограничены источники запросов (CORS), добавьте адрес сайта. Разместите этот HTML на HTTPS-хостинге и открывайте одну ссылку на всех устройствах. Сам HTML не публикует сайт.

Данные загружаются при открытии страницы. Кнопка «Обновить» получает изменения с других устройств; автоматическое обновление можно включить ниже. Во время редактирования оно приостановлено. При отсутствии сети запись недоступна; уже загруженные данные остаются на экране.

Для переноса старой базы скачайте JSON в прежней версии и нажмите «Импорт JSON». Импорт добавляет отсутствующие ID, существующие проекты пропускает. Демоданные автоматически не создаются. Адрес API виден посетителям; доступ к странице сам по себе не ограничивает доступ к API. Ссылка Битрикс24 открывает задачу без синхронизации.

Перед записью проверяется, не изменился ли проект. Эта проверка не является транзакционной блокировкой: одновременное сохранение одной карточки на двух устройствах может привести к перезаписи. Редактируйте одну карточку на одном устройстве за раз. Автообновление расходует лимит запросов SheetDB.

Подключение…

Готовность — среднее шести этапов с одинаковым весом. Закрытие проекта доступно при 100% всех этапов и заполненной фактической дате завершения. Оплаты и металлокаркас контролируются отдельно. Размеры экрана — мм, площадь — м². Суммы — ₽. Просрочка считается по текущей дате устройства. Общие показатели сверху не зависят от фильтров.
